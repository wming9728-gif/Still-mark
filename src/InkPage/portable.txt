InkPage portable copy
=====================
Because this file is here, InkPage keeps its settings, recent files and recovery drafts in the "data"
folder next to InkPage.exe, so the whole folder can be moved or copied as it is.
(The installed version keeps them in %LOCALAPPDATA%\InkPage instead.)

InkPage 便携版
==============
因为有这个文件，InkPage 会把设置、最近打开的文件和恢复草稿保存在 InkPage.exe 旁边的 data 文件夹里，
整个文件夹可以直接移动或复制。（安装版则保存在 %LOCALAPPDATA%\InkPage。）
